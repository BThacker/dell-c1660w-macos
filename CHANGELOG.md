# Changelog

## 1.0.0

- First stable release: native Apple Silicon driver for Dell C1660w Wi-Fi
  printing on macOS 26+.
- Color/grayscale, Letter/A4, page selection, and copies.
- Installer, setup/diagnostic/uninstall tools, source archives, and checksums.
- Software tests and optional signing/notarization workflow.
